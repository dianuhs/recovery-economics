# Scenario status

The canonical v0.2 schema is `recovery-economics/2.0`; see `examples/scenario-v2.yml`.

The older YAML files in this directory are retained as legacy research inputs. They use multiple incompatible, pre-v0.2 shapes and are not accepted by the canonical CLI. They must not be cited as executable examples or pipeline evidence. A future comparison release may migrate their multi-strategy concepts into a separately versioned scenario-set contract.
